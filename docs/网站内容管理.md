# 作品集网站内容管理

网站代码、配置、生成快照和发布历史全部保存在 `Portfolio Site` 仓库中；Obsidian 的 `02_Portfolio` 仅作为原始项目文档与素材的只读内容源，不再存放网站配置文件。

## 日常更新

1. 在 Obsidian 的 `02_Portfolio` 各项目文件夹内维护 Markdown 和素材。
2. 在网站仓库根目录的 `portfolio.config.json` 调整项目顺序、标题、摘要、强调色、发布状态与是否加锁。
3. 新增项目时先在 Obsidian 创建项目文件夹，再在 `portfolio.config.json` 增加对应项目；若暂时没有成稿，可设为 `previewOnly: true`。
4. 网站同步时会生成一份可追踪的内容快照。每次发布都对应一个明确版本，可以回看某次发布实际使用了哪些文案与素材。

## 内容约定

- `entry` 指定该项目对外呈现的主文档。
- `startAt` 与 `endBefore` 用于从研究底稿中选择公开区间，避免编辑备注和附录直接出现在网站。
- 文档里的二级标题会自动成为项目侧边栏导航。
- Obsidian 图片嵌入 `![[路径/图片.png]]` 会在同步时自动复制到网站快照。
- `protected: true` 表示进入项目详情前需要密码；密码不写进本文件，也不会进入版本历史。
- 联系方式的 `href` 目前留空；补上链接后才会成为可点击入口。

## 发布判断

`previewOnly: true` 的项目只展示经过整理的项目命题和状态，不公开草稿正文。材料准备好后改为 `false`，网站会从 `entry` 指定的主文档生成详情页。
